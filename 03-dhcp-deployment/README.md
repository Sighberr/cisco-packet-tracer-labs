# 03 - DHCP Deployment

## Overview

Configured DHCP to automatically assign IP addresses to client devices in a multi-department office network.

## Goal

Replace manual IP configuration with automatic IP assignment.

## Devices

- Cisco 2911 Router
- 2 Cisco 2960 Switches
- 4 PCs
- 2 Printers
- 1 Server

## Skills

- DHCP Configuration
- Dynamic IP Addressing
- Static IP Addressing
- Network Testing

## Results

- Configured DHCP for client devices.
- Assigned IP addresses automatically.
- Verified network connectivity.
