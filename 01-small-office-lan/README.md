# 01 - Small Office LAN

## Overview

Built a small office network in Cisco Packet Tracer with three PCs and one network printer connected to a Cisco 2960 switch.

## Goal

Configure a basic LAN using static IP addresses and verify communication between all devices.

## Devices

- Cisco 2960 Switch
- 3 PCs
- 1 Network Printer

## Skills

- Static IP Addressing
- LAN Configuration
- Cisco Packet Tracer
- Ping Testing

## Results

- Configured all devices with static IP addresses.
- Verified successful communication using the `ping` command.
- Confirmed all devices were connected on the same local network.
